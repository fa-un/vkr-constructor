# Конструктор тем ВКР

Интерактивный конструктор тем выпускных квалификационных работ для бакалавров
38.03.05 «Бизнес-информатика» (Финансовый университет, кафедра бизнес-информатики).

Студент отмечает критерии: форму работы, материалы, отрасль, процесс, участников
проекта (владелец, исполнитель, заинтересованные стороны), техники BABOK, уровень
автоматизации AS-IS и TO-BE, контуры систем, метрики (отраслевые и общие), методы анализа и
прогнозирования в трёх группах: описать, предсказать, предписать (при контурах BI/DSS/ML), подход к управлению проектом с подсказкой типичного варианта и артефакты. Справа собирается паспорт темы по
требованиям программы ГИА кафедры: формулировка не длиннее 11 слов, объект и
предмет, задачи, структура глав, строка «Методы», KPI, инструменты, чек-лист и календарь. Методологии, порядок действий и отраслевая нормативная база вынесены в необязательную справку внизу страницы.
Паспорт вместе с отмеченными опциями копируется в Markdown.

- `vkr_constructor.html` — приложение, один файл без сборки; откройте в браузере.
- `vkr_constructor_requirements.md` — нормативная база, структура опций, правила
  согласованности, логика генерации, идеи для следующих версий.
- `cases/` — паспорта тем, выгруженные из конструктора в Markdown (пример: `sklad-komplektatsiya-zakazov.md`,
  комплектация заказов и размещение товара на складе торговой компании).
- `index.html` — та же страница в полной HTML-обёртке для GitHub Pages; собирается скриптом `./build.sh`,
  вручную не редактируется.
- Онлайн: https://fa-un.github.io/vkr-constructor/ (GitHub Pages)
  и https://claude.ai/artifact/CPS8kRLg8SBUcxDU4NZpGB (артефакт claude.ai).
