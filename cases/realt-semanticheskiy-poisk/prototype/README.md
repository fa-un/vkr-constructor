# Прототип поиска недвижимости

`metrapi-gallery.html` — автономная демонстрация этапа 0 поиска по естественному языку на локальном снимке данных Metrapi.

- 10 объектов продажи квартир в Санкт-Петербурге;
- все фотографии из сохранённой выборки;
- цены и ссылки на первоисточники скрыты;
- цветовая шкала и демо-ранжирование по близости к метро, полноте адреса и наличию фотографий;
- поле естественно-языкового запроса с разбором на жёсткие фильтры, мягкие предпочтения и неподдержанные критерии;
- предпросмотр параметров будущего запроса к `GET /v1/public` без фактического обращения к внешнему API;
- лайк, дизлайк и избранное работают в рамках текущей страницы без персистентности.

Страница использует `listings.js`, поэтому её можно открыть напрямую как локальный HTML-файл без `fetch` и локального сервера.
